💻 Welcome to Small Computer Workshop (SCW)

                  

                    Small Computer Workshop is an integrated development environment (IDE) originally designed by Stephen C. Cousins for developing Z80 and Z180 assembly language software.
                    This web edition combines an in-browser Z80/Z180 Source Editor, a built-in two-pass Assembler, an animated Simulator & Cycle-Accurate Hardware Emulator (SC131 Pocket Computer, SC126 RCBus Motherboard, and Simulated Z80), an interactive Disassembler, a 512 KB Memory Hex Viewer, a step-by-step Instruction Trace Recorder, and live Hardware Diagnostics.
                  

                  

                    
                    
                    
                  


                  
                  

                    
Interactive Test Execution:

                    
1. Select SC126 Z180 RC2014 Motherboard target

                    
2. Load SCM_LED_Light_Show.asm into Code Editor

                    
3. Run Two-Pass Assembler & write machine code to RAM $8000

                    
4. Switch workbench to Split View (Editor + Terminal)

                    
5. Start animated Walk mode (~12 ips) & highlight executing lines

                    
6. Open Bottom Panel to Simulation Trace to verify recorded steps

                  

                


                
                

                  

                    1
                    Choosing Your Target Machine & Architecture
                  

                  

                    The workshop supports three distinct target computers. Select your target using the top titlebar dropdown or the Machine menu:
                  

                  
    
                    
  • 
                      SC131 Z180 Pocket Computer: Portable Z8S180 microcomputer @ 18.432 MHz, 512 KB Flash ROM, 512 KB SRAM, SPI MicroSDHC card slot, dual ASCI serial ports, DS1233-5+ voltage supervisor, and Orange Status LED1 on Port $0E bit 2. Runs RomWBW v3.6.0, CP/M, and Fuzix Unix.
                    
    • 
                    
  • 
                      SC126 Z180 RC2014 Motherboard: RCBus / RC2014 modular motherboard with Z8S180 CPU, Port $0D (13) 8-LED diagnostic bar (74HCT273), and Dallas DS1302 Real-Time Clock with battery-backed NVRAM.
                    
    • 
                    
  • 
                      Simulated Z80 Computer: SCWorkshop's classic educational target with flat 64 KB RAM, Port $00 8-LED output bar and 8-bit interactive toggle switches, 64×32 memory-mapped character display at $4000–$47FF, line printer at Port $03, and hardware /INT0 push button.
                    
    • 
                  

                  

                    Tip: The Right Hardware Sidebar dynamically adapts to the selected machine, showing only real physical components for that board!
                  

                  

                    
                    
                    
                  

                


                
                

                  

                    2
                    Using the Code Editor & Two-Pass Assembler
                  

                  

                    Switch to the Source Editor tab to write or inspect assembly code. The editor features a line gutter, error markers, automatic 4-space Tab indentation, and live cursor position telemetry (Ln/Col in the status bar).
                  

                  
Essential SCWorkshop assembly directives:

                  
            #TARGET     SC126           ; Sets architecture: SC126, SC131, or Simulated_Z80
            .PROC       Z180            ; Enables Z180 opcodes: MLT, IN0, OUT0, TST, OTIMR
            .ORG        8000h           ; Sets origin address ($8000 in RAM or $0000)

DiagPort:   .EQU        0Dh             ; Port 13: SC126 8-LED Diagnostic Bar
Start:      LD   B, 4                   ; Loop 4 times
ScanLoop:   LD   A, 01h                 ; Start with bit 0 (LED L0)
ShiftLeft:  OUT  (DiagPort), A          ; Output byte to Port $0D LEDs!
            CALL Delay                  ; Software delay loop
            RLCA                        ; Rotate left to next LED bit
            JR   NC, ShiftLeft
            .END

                  

                    Two-Pass Assembly: Press F7 or click ⚙ Assemble. Pass 1 calculates symbol addresses and evaluates expressions (supporting $, %, 0x, h, HIGH, LOW). Pass 2 generates machine code and produces:
                    
    
                      
  • Listing.txt: Machine code bytes alongside source lines with clickable breakpoint markers.
    • 
                      
  • IntelHex.hex: Industry-standard Intel HEX records for burning or serial transfer.
    • 
                      
  • Memory.txt & Symbols.txt: Hex byte dumps and resolved symbol tables.
    • 
                    

                  

                  

                    
                    
                    
                  

                


                
                

                  

                    3
                    Executing Code: Run, Jog, Walk & Step
                  

                  

                    The workshop provides 4 simulation speeds so you can choose between maximum execution throughput and detailed instructional stepping:
                  

                  
    
                    
  • 
                      Run (F5 / F8): Full-speed hardware emulation (18.432 MHz real-time or turbo). Perfect for running RomWBW, CP/M, WordStar, and Fuzix Unix.
                    
    • 
                    
  • 
                      Jog Mode (~600 instructions/sec): Medium animated speed. Watch registers and LEDs shift rapidly while maintaining smooth visual updates.
                    
    • 
                    
  • 
                      Walk Mode (~12 instructions/sec): Educational stepping mode! Highlights the executing source line in gold in the editor, pulses the hardware LEDs, updates the CPU registers, and appends each instruction to the Trace buffer.
                    
    • 
                    
  • 
                      Step (F10): Single instruction execution. Executes one Z80/Z180 opcode and halts immediately.
                    
    • 
                  

                  

                    
                    
                    
                    
                    
                  

                


                
                

                  

                    4
                    Viewing the Simulation Trace
                  

                  

                    During Step, Walk, and Jog modes, the workshop records a cycle-by-cycle instruction trace in the docked bottom panel (Ctrl+J).
                  

                  

                    Each trace row displays the exact CPU state before instruction execution:
                  

                  
    
                    
  • STEP: Sequential instruction execution count.
    • 
                    
  • PC: 16-bit program counter address (e.g. $8007).
    • 
                    
  • BYTES: Hex opcode and operand bytes (e.g. D3 0D for OUT (0Dh), A).
    • 
                    
  • INSTRUCTION: Disassembled Z80 mnemonic with symbolic operands.
    • 
                    
  • AF, BC, DE, HL, SP: 16-bit register states.
    • 
                    
  • FLAGS: CPU flag bits (SZ5H3PNC: Sign, Zero, Half-Carry, Parity/Overflow, Add/Subtract, Carry).
    • 
                  

                  

                    Use trace to verify algorithm logic, identify runaway loops, or audit peripheral I/O writes.
                  

                  

                    
                    
                  

                


                
                

                  

                    5
                    Using the Disassembler & Setting Breakpoints
                  

                  

                    The built-in disassembler decodes instructions directly from target memory, including all standard Z80 and Z180 extended opcodes (such as MLT, IN0, OUT0, TST).
                  

                  
    
                    
  • Jump to Current PC (@PC): Instantly centers the disassembly view around the executing instruction.
    • 
                    
  • Arbitrary Address Browsing: Type any hex address in the Addr box (e.g. 8000 or 0000).
    • 
                    
  • 
                      Interactive Breakpoints:
                      Type a hex address into BP Hex and click +BP, or click directly on any address in Listing.txt! When the CPU hits a breakpoint address, execution stops immediately, switches bottom panel to disassembler, and highlights the address in red.
                    
    • 
                  

                  

                    
                    
                  

                


                
                

                  

                    6
                    Using the Memory Hex Inspector
                  

                  

                    Inspect memory across all three hardware address spaces:
                  

                  
    
                    
  • Logical CPU (64 KB): The CPU's current memory view translated through the Z180 MMU registers (CBAR, BBR, CBR).
    • 
                    
  • Physical ROM (512 KB): The SST39SF040 Flash memory containing RomWBW or Small Computer Monitor.
    • 
                    
  • Physical SRAM (512 KB): The AS6C4008 512K static RAM chip.
    • 
                  

                  

                    The inspector uses 60 FPS DOM virtualization, allowing smooth scrolling across all 524,288 bytes without lag. Use the quick jump buttons ($0000, $0100 for CP/M TPA, $4000 for Screen, $8000 for User Apps, @PC, @SP, @HL) to navigate instantly.
                  

                  

                    
                    
                    
                  

                


                
                

                  

                    7
                    Other Workshop Possibilities & Tools
                  

                  
    
                    
  • 
                      Side-by-Side Split View (⧉): Work with your Z80 assembly source editor and serial terminal side-by-side with zero floating windows.
                    
    • 
                    
  • 
                      Number Base & ASCII Converter: Open the Convert sidebar (Tools or Edit › Conversions) to translate in real-time between Hex, Unsigned Decimal, Signed 16-Bit (-32768..32767), Binary High Byte, Binary Low Byte, and ASCII character.
                    
    • 
                    
  • 
                      Simulated CRT Screen & Printer: In the Sim Screen & Printer tab, view the 64×32 character amber CRT ($4000–$47FF) and dot-matrix Line Printer (Port $03) paper feed.
                    
    • 
                    
  • 
                      Hardware Sidebar Enclosure: Toggle switches and LEDs with real-time feedback, view DS1302 Real-Time Clock registers, adjust the DS1233 supply voltage slider to test brownout reset behavior, and mount/export MicroSD disk images.
                    
    • 
                    
  • 
                      ⚡ Quick Boot Menu: Instantly launch CP/M 2.2, ZSDOS, CP/M 3, WordStar 4, Turbo Pascal, BASIC 4.7b, CamelForth, or Fuzix 0.4 Unix OS with a single click.
